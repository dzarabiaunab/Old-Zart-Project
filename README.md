# Proper Explanation of Prototype
This repository stores a fraction of a project put together by a team. This is my part of the work. It uses Godot 4.1 Mobile.

## Scripts
The repository stores the player file, followed by the menu buttons, bullets, enemies and enemy movement for a specific bug enemy.

## Scenes
Godot allows the user to separate each moving part of a game into "Scenes". In this current version of the project, they include the camera, main menu, enemies, bullets, the player and level layout.

### Build?
This project is not meant to be built on a different environment, as it is only a showcase of the work.
